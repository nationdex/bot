# Nationdex F.A.Q

**1st Question:** Why Nationdex has lots of similarities with Ballsdex?
> **Answer:** Nationdex was originally created as an direct alternative to Ballsdex ever since BD almost got cancelled after an situation between El Laggron and Speedroide, and back then, Nationdex used to be made in BDFD, until it reached a breaking point where it had to begin using the Ballsdex code after the insane growth which it had back in 2023.

**2nd Question:** Why some Nationdex arts are old or effortless?
> **Answer:** It is simple to answer, Nationdex has an old storage of its arts from the golden era of the dex community, which was needed to be used in order to ensure the revival of Nationdex did not rely on the lame and compromised teamwork of artists from the WCB era which still haunts Nationdex to this day. Yeah, the Nationdex artists are not that much active at all, whenever we need them the most.

**3rd Question:** Why Project Nationdex 2026 is using NPM over Bun or PNPM?
> **Answer:** The current status of ForgeScript and its extensions has forced us to take a step back and utilize the default NPM, in order to allow the modules from BotForge to run flawlessly without any unhinged incompatibility issues, but we might try to create our own BotForge module to sort that issue or just create forks of the existing ones.

**4th Question:** Why the bot takes far too long to install modules?
> **Answer:** It is because NPM is extremely slow when installing all the necessary modules for the Project Nationdex 2026 codebase to work, and as much as we wanted to use Bun and we still seek to use Bun at any opportunity, we were sadly forced into this due to the limitations from ForgeScript and its extensions. Therefore, it is recommended that you run the command and wait for it to install everything though, because we cannot do anything as long as something is made inside BotForge's modules to ensure compatibility with Bun.

**5th Question:** Why is Nationdex always sticking towards BDFD and BotForge at every opportunity?
> **Answer:** Nationdex's history, despite its dark situations related to dramas, fights, and arguments, always had strong ties with BDFD and principally BotForge, due to Nationdex being originally created as an BDFD alternative to Ballsdex after all, but surprisingly, Nationdex has so much ties with the BotForge community that it has developers such as Aditya and Ayansh operating and building this codebase here as we speak, and they came (or were) from the BotForge community.

**6th Question:** What is BotForge and ForgeScript?
> **Answer:** BotForge is an association of developers dedicated to push beyond the limitations of BDFD and build an easy-to-use scripter for JavaScript & TypeScript, which is named ForgeScript.

**7th Question:** What are those BotForge extensions on the Project Nationdex 2026 codebase?
> **Answers:** Modules such as ForgeDB and ForgeCanvas for example are extensions created by the BotForge Team for certain tasks which the main ForgeScript cannot do, and those modules can serve as compatibility-wise replacements for common JS/TS ORMs, image generation tools, etc.

**8th Question:** What is BDFD aka Bot Designer for Discord?
> **Answer:** BDFD is an mobile app created for those who do not know that much about programming to build an Discord bot with ease through an very easy scripting language called BDScript 2, but BDFD has several issues related to the requirement to watch advertisements and the very limitations which can even make it unable to be ran in Discord bots with more than 1.5K or 2K guilds, which led to the creation of Aoi.js, and later on, ForgeScript.
