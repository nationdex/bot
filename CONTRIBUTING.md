# Contributing and Volunteering

My gratitude to those who seek to contribute and volunteer themselves for Project NationDex 2026 is incredibly immense, and you have no idea how much it flatters my heart to see NationDex being valued by you at some point. Thank you for your dedicated assistance to make the dex community blue and united again.

Now, allow us to inform you about the requirements to operate on the Project NationDex 2026 and assist on its development.

## Prerequisites

Before anything, please make sure to install Node.js through their official [website](https://nodejs.org/), and then, follow the instructions from the [readme](https://github.com/nationdex/bot#readme) file to setup the codebase and test it on your environment.

## Recommended IDEs

- Visual Studio Code

> VS Code is the main IDE anyway, nothing can escape the almighty Microsoft.

- Antigravity

> If you want an AI-driven IDE by your side to do a lot of hallucinations on the ForgeScript codes and make you suffer in the process, then use Antigravity lol.

## Recommended Extensions

- ForgeLSP

> THIS IS IMPORTANT SIR! ForgeLSP gives ForgeScript an actual type-safe layer on the codebase, making it easier to develop and maintain.

- NPM Intellisense

> This extension is for you to import modules and stuff with ease, without causing you a headache or whatever.

- Code Spell Checker

> If you are bored and don't know what to do on the codebase, then you can fix the silly grammar mistakes which we do sometimes, by using this extension. However, this extension is not mandatory to be used.
